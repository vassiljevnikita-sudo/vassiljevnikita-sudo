Pharmacy student at FU Berlin, building AI tools for regulated work.

## Projects

### Questify

A to-do app in German where finished tasks earn XP and levels, and friends compete on a season leaderboard. Released as an Android APK and as a web app; the source code is private, the repo holds the APK releases.

[Open the app](https://mastertasker.expo.app/willkommen/) · [Releases repo](https://github.com/vassiljevnikita-sudo/questify-releases)

### Complaint Dossier

A PowerShell workflow that turns complaint cases into a draft Word report with Microsoft 365 Copilot; the report stays marked DRAFT until a reviewer signs, and a JSON audit log records SHA-256 hashes of inputs and outputs. `./Invoke-ComplaintDossier.ps1 -Demo` runs on synthetic cases without Copilot, and CI uploads the sample `.docx` on every run.

[Demo runs (Actions)](https://github.com/vassiljevnikita-sudo/complaint-dossier/actions) · [Repo](https://github.com/vassiljevnikita-sudo/complaint-dossier)

### QBD research

Research on how to train and select stock-selection models over time without leaking future information: 2,790 model families and 1.63 billion matured prediction rows from 2016 to 2025. No tested learned selector cleared the promotion gates, and the repo documents what failed and why. No real capital is involved.

[Demo](https://simple-light-qbd.expo.app/) · [Repo](https://github.com/vassiljevnikita-sudo/simple-and-light-research)
